# Banking System App 🏦


---

## 📜 About this Software 

A simple banking system software built fully in Python.
<br>
It solves the problem of session handling and Real-time data handling.
<br>
CustomTkinter is used for making Modern GUI.
<br>
SQLite is used for making Database, Session Handling and Real-time data handling.

---
## 🚀 Features
- Login System
- Deposit Money
- Only Runs on Windows
- Payment
- Check Balance
- Session Management
- Logout System
- Modern GUI
- .exe file options

---

## 🧰 Tech Used
- Python 🐍
- CustomTkinter
- SQLite
- PyInstaller

---

## ▶️ How to Run

### Option 1 : Run using Python
1. Copy the Repo
   
2. Install CustomTkinter
   ```
   pip install customtkinter
   ```
3. Run the file
   ```
   python main.py
   ```

### Option 2 : Run the executeable file
1. Copy the Repo
2.  Install PyInstaller
   ```
   pip install pyinstaller

   ```


3. Run this command where main.py is there 
   ```
   python -m PyInstaller --onefile --noconsole --icon=ICON/bank.ico --collect-all customtkinter main.py
   ```

4. Open Dist directory and click on the .exe file
