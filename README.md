# Banking System App 🏦


---

## 📜 About this Software 

A <b> Simple Banking System Software </b> built fully in Python.
<br>
It solves the problem of Session handling and Real-time data handling.
<br>

---

## 🚀 Features
- Login System
- Deposit Money
- Only Runs on Windows
- Payment
- Check Balance
- Session Management
- Logout System
- Modern GUI
- .exe file options

---

## 🧰 Tech Used

- Python 🐍
<br>

- CustomTkinter
<br>

- SQLite
<br>

- PyInstaller

## 📚 Modules & Libraries Used in it 
<br>

- <b> CustomTkinter </b> : Used for making Modern GUI.

---

## ▶️ How to Run

### Option 1 : Run using Python
1. Copy the Repo
   
2. Install CustomTkinter
   ```
   pip install customtkinter
   ```
3. Run the file
   ```
   python main.py
   ```

### Option 2 : Run the executeable file
1. Copy the Repo
2.  Install PyInstaller
   ```
   pip install pyinstaller

   ```


3. Run this command where main.py is there 
   ```
   python -m PyInstaller --onefile --noconsole --icon=ICON/bank.ico --collect-all customtkinter main.py
   ```

4. Open Dist directory and click on the .exe file
